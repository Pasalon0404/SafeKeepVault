Unlock your vault with a security key, such as a YubiKey: type its PIN and touch it, alongside your Master Passphrase or instead of it. ### 🔐 Security keys
A FIDO2 security key with the hmac-secret feature can unlock the vault with its PIN and a touch: YubiKey 5, Security Key by Yubico, Nitrokey 3, SoloKey 2, Google Titan and most current keys. Keys without it, and older U2F-only keys, are refused with a plain message.
- **Three ways to unlock**, under **How should this vault unlock?**: **Master Passphrase (recommended)** (the default, unchanged), **Passphrase or security key**, or **Security key only**.
- **At first setup** the choice comes right after the welcome screen. With **Security key only**, SafeKeep adds the key (setting a PIN of at least 6 characters if it has none), checks that it opens the vault, and offers to add a spare. No passphrase is ever created.
- **Later**, in **Device Options → Security Keys → Manage Security Keys → Lock and Manage**: add a key (up to 4), rename or remove one, switch to **Use security keys only**, or **Add a Master Passphrase** back. Each key must open the vault before the passphrase can be removed.
- **Unlocking:** choose **Use a Security Key**, plug in the key, type its PIN and tap it when it blinks. The screen confirms each step: "PIN accepted", "✓ Touch received. Unlocking your vault…". A short tap is right: holding a YubiKey for about 3 seconds makes it type a one-time code.
- **Know the risks:** after 8 wrong PINs (on most keys) a key locks for good. With Security key only, losing every key means the vault can't be opened: your seed backup still restores the wallet, and saved wallets, the Passphrase Library and notes come back only from an Encrypted Backup. A spare key kept somewhere else is recommended.
- **Why it's strong:** with Security key only, someone who copies the flash drive has nothing to guess offline, and the key allows only a few PIN guesses. Nothing is stored on the key.
- **USB safety:** a security key plugged in after start-up (directly or through a hub) is let through, but only its FIDO2 part. Any late device that tries to type as a keyboard is muted, and the kernel's SysRq keys are off.

Tested with a YubiKey. Other FIDO2 keys are supported but not yet tried on a real device.

### 🎲 Entropy Generator
- **The meter stays in view:** the meter and **Generate Seed** sit in one bar that stays at the top while you scroll through the sources. The pool hash and raw pool fold into one **Show the entropy pool** section.
- **Mouse Wiggle** shows the bits it has added ("… / 64 bits from the mouse") and says when its share is full. The mouse can fill at most half the meter; Reset clears it.
- **Video Noise:** each **Capture Video Noise** turns the camera on for about a second, takes 5 frames and turns it off.

### 📨 The Courier
- **Receive:** long text sent from the online Courier Tool as an animated QR code now arrives whole. It used to show only the first piece. Animated BBQr codes work too, and a PSBT sent this way is offered as a file to save.
- Received text keeps its line breaks, and stays hidden until **Show**.

### 🔄 Update in place from v1.47 or later
1. Copy `SafeKeep-Update-v1.67.tar` onto your flash drive's TRANSFER drive.
2. Boot SafeKeep and unlock your vault.
3. Open Device Options → Update SafeKeep → Check for update, then Install and Restart now.

Your vault, how it unlocks and your Transfer Drive are not touched. Before installing, SafeKeep shows the app's SHA-256: it should match the `boot.html` line of this release's `SHA256SUMS`.
