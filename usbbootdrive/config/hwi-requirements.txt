# Trezor USB support for SafeKeep (installed by chroot-setup.sh into
# /opt/safekeep-hwi with `pip install --require-hashes`).
#
# Bitcoin Core's HWI library (hwilib) and every package it pulls in, each
# pinned to an exact version AND its SHA-256, resolved for Ubuntu 24.04
# (Python 3.12, x86_64) and checked against PyPI on 2026-10-01. pip refuses
# to install anything whose fingerprint does not match. To upgrade, change a
# version, re-check its hash on pypi.org, and test against the real Trezor
# before building.
#
# HWI 3.2.0 supports Python >=3.9,<3.13. Ubuntu 24.04 ships 3.12.
# hidapi, ecdsa, six and pyaes are the same files (same hashes) as in
# ckcc-requirements.txt. pyaes ships only as source: it is built with the
# hash-pinned setuptools from ckcc-build-requirements.txt and
# --no-build-isolation, so pip never fetches an unpinned build tool.
#
# libusb1 is a pure-Python wrapper: it needs Ubuntu's libusb-1.0-0 package
# (installed by chroot-setup.sh) to reach the Trezor One over WebUSB.
#
# Some packages are only used by HWI's code for OTHER devices and are never
# touched on the Trezor path: noiseprotocol (+ cryptography, cffi, pycparser)
# and semver for BitBox02, cbor2 for Jade. They are HWI's declared
# requirements, so they are pinned and installed rather than left out.
